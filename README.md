# kbbs — 宣伝OKの1ファイル掲示板（Kurage BBS）

会社・お店・サービスの宣伝を**歓迎**する掲示板。ホームページへのリンク投稿OK（バックリンクになります）。

「宣伝お断り」の掲示板が多い中、kbbsは逆の設計です。そのかわり、なりすまし・スパムを構造的に防ぎます:

1. **𝕏（旧Twitter）ログイン必須** — 匿名の荒らしを排除
2. **宣伝するURLと同じドメインのメールアドレスが必要** — その会社のご本人様しか投稿できない

## 特徴

- **1ファイルPHP**（kbbs.php）・**DB不要**（同ディレクトリのファイルに保存）
- PHPが動くレンタルサーバーにFTPで置くだけ
- 連投制限（1ユーザー1日1回）・CSRF対策・投稿データはWeb直読み不可
- 管理者ビュー（`?admin=1`）: 投稿者の𝕏・会社URL・メールを一覧し、フォロー/DMボタンから営業アプローチできる
- MITライセンス

## 動作例

https://kurage.exbridge.jp/kbbs.php

## 設置

1. `kbbs.php` をWebルートに置く
2. 𝕏認証（`auth_common.php` 相当のOAuthブートストラップ）を用意して `require` を合わせる
3. ブラウザで開く

（Kurage App Store 版には、AIエージェント向けの設置・改変マニュアルが同梱されます）
